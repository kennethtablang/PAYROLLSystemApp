# Installing Payroll Management System

For the person installing the app at the company. It takes about five minutes.

## 1. First install (one time only)

1. Get `PayrollSystemSetup-1.1.exe` from the developer (Google Drive, Messenger
   or a USB drive).
2. Double-click it.
3. Windows may show a blue box that says **"Windows protected your PC"**.
   This appears for any new program that Windows has not seen many times
   before. It does not mean the file is harmful.
   - Click **More info** (the small link under the text).
   - Click **Run anyway**.

   **If you do not see "Run anyway"**, do this instead:
   right-click the file → **Properties** → at the bottom of the *General* tab,
   tick **Unblock** → **OK**. Then double-click it again.

4. In the installer choose **Install for me only** (no administrator password
   needed) unless you were told otherwise. Click **Next** until **Finish**.
5. Sign in with the account the developer gave you, then change the password
   in **Settings → Change password**.

### Still blocked?

| What you see | What to do |
|---|---|
| No **More info** link, or "Your administrator has blocked this app" | The PC is managed by your IT staff. Ask them to allow `PayrollSystemSetup-1.1.exe`, or to install it for you. |
| "The app you're trying to install isn't a Microsoft-verified app" | Open **Settings → Apps → Advanced app settings → Choose where to get apps** and set it to **Anywhere, but let me know if there's a comparable app in the Microsoft Store**. Then try again. |
| "Smart App Control blocked an app" | Message the developer. Do **not** turn Smart App Control off. |
| The antivirus deletes or quarantines the file | Restore it from the antivirus and add `C:\Users\<you>\AppData\Local\Programs\Payroll Management System` to its exclusions. |

## 2. Updates (after the first install)

You do **not** download or install updates by hand any more.

1. Keep the PC connected to the internet. The app looks for new versions by
   itself every half hour, and soon after the internet comes back. When the
   developer publishes one, a blue strip appears at the top of the app:
   *"A new version is available"*. (Versions 1.1 and older only look when
   someone signs in.)
2. Anyone can click **Download**. The app keeps working while it downloads; a
   progress bar shows how far it is. If the internet drops, the download
   carries on by itself once it is back. **Later** hides the strip until the
   next sign-in.
3. When the strip says *"ready to install"*, an **administrator** clicks
   **Install** (also under **Help & Updates**). **What's new** shows what
   changed.
4. The app takes a backup, closes, updates itself and opens again. This takes
   about a minute. You will not see the "Windows protected your PC" warning
   again, because the app downloads and checks the file itself.

Before updating, make sure nobody else is using the app.

If something is wrong after an update, use **Backup & Archive → Restore** with
the backup taken just before the update. It is the newest one in the list. Then
tell the developer.

## 3. Reporting a problem or asking for a change

1. Open **Help & Updates** in the sidebar.
2. Under **Report a problem or request a change**, choose what kind, how
   urgent, and which screen. Then write a title and the details: what you did,
   what you expected, and what happened. Use real figures when you can.
3. To add screenshots, press **Windows + Shift + S**, select the area, save
   the picture, then click **Add files**.
4. Click **Save request file**. A folder opens with a file such as
   `REQ-261006-1430.zip` already selected.
5. Send that file to the developer by Messenger, e-mail or Google Drive.

Quote the reference (`REQ-…`) when you talk about it. When it is fixed, the
**What's new** text of the update will name it.

Only tick **Include a copy of the database** when the developer asks for it.
That copy holds every employee's pay and personal details, so send it
privately and directly to the developer.
