# Revision log

Every request from the company, from the day it arrives to the version that
answers it. One row per `REQ-` reference. The request zips themselves stay
**out of the repository** (they can hold payroll data). See
[WORKFLOW.md](WORKFLOW.md) for where they go.

Status: `New` → `Accepted` / `Declined` / `Need info` → `In progress` → `Done in x.y`.

| Reference | Received | Kind | Priority | Title | Status | Notes |
|---|---|---|---|---|---|---|
| _REQ-yyMMdd-HHmm_ | _2026-10-06_ | _Problem / Change / Question_ | _Urgent / Normal / Low_ | _short title from REQUEST.txt_ | _New_ | _decision, cost, link to commit_ |
